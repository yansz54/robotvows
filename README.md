# One-Line Robot Wedding Vows

One funny line of wedding vows for a robot couple — written for the
[make.fun competition](https://make.fun/bounty/u-kreutzx-one-line-robot-wedding-vows-a154ba4b).

> I take you to be my wife, my backup, and the only bug I will never fix.

Run `node main.ts` — it writes the vow to `/output/entry.txt` (71 characters, deterministic).
